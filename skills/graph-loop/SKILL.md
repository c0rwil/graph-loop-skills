# Graph Loop

Follow [the kickoff prompt](../../prompts/kickoff.md) for primary coding tasks. Use the installed `graph-loop` command or `python3 /path/to/graph-loop-skills/gl.py`. All runtime state stays outside source checkouts.

Tiny tasks may keep criteria in the task. For substantial or multi-repository changes, register explicit `alias=checkout` members with one shared `alias:spec.json` behavior contract. Give acceptance criteria stable IDs and repository owners. Use `workspace align NAME --run` to execute repository checks. Graph alignment is not deployed compatibility.

Use Graphify navigation, confirm exact source with `read`, implement the smallest coherent slice using Ponytail, and execute relevant `check` commands. Hooks refresh graphs and collect only supported evidence; missing metadata never implies success. Shunt bulk reads and >80% predictable generation to independent workers. The primary retains architecture, debugging, difficult edits, integration and final verification. Respect read-only planning and local delegation rules.

Use `finding --receipts ...` for meaningful agent-authored conclusions; corrected outcomes require an actual correction. Receipt provenance does not prove all acceptance criteria. Primary-turn completion automatically curates up to three findings from current verified receipts and runs deterministic reflection. Failures and oversized documents remain pending in `status`. Stop when the behavior contract and required checks pass; do not add an approval pause to authorized work.

See [runtime operations](../../docs/operations.md) and [provider setup](../../docs/providers.md).
