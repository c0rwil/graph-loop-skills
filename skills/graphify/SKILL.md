# Graphify

Use `graph-loop refresh` before `query`, `path` or `explain`. Query commands also refresh automatically. Code extraction uses isolated pinned `graphifyy==0.9.104`; semantic extraction uses complete changed eligible text through the chosen harness worker. Oversized/media/incomplete inputs remain pending. Never substitute a Shunt summary for semantic input.

One canonical graph belongs to each exact checkout ID in the external state directory. Linked worktrees never share local graphs. Workspace merges namespace IDs and retain aliases, unambiguous paths, branch/HEAD/dirty source state and graph hashes. Missing/stale inputs preserve the prior published graph and expose pending errors. Register only explicit local paths; do not scan unrelated repositories.

Inferred links require source confirmation. No graph path does not prove independence. Confirm exact lines with `graph-loop read` and relevant executable checks. The graph is a navigation aid, not proof of acceptance or deployment compatibility. [Operations](../../docs/operations.md).
